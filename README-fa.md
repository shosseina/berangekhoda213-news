# 📰 از به‌رنگ‌خدا چه خبر؟

این نسخه یک نمونه وب‌اپ ساده برای تولید خبرهای هفتگی «از به‌رنگ‌خدا چه خبر؟» است.

## چیزی که الان دارد

- صفحه ساده و مناسب موبایل
- ورود متن خام خبر
- ورود صوتی فارسی با قابلیت Speech Recognition مرورگر در مرورگرهای سازگار
- تولید خبر با OpenAI API
- کپی سریع متن خروجی
- دستورالعمل ثابت مخصوص لحن «از به‌رنگ‌خدا چه خبر؟»

## راه‌اندازی

نیاز به Node.js دارید.

1. این پوشه را باز کنید.
2. ترمینال را در همین پوشه باز کنید.
3. اجرا کنید:

```bash
npm install
```

4. فایل `.env.example` را به `.env` تغییر نام دهید.
5. کلید API خودتان را داخل `.env` قرار دهید.
6. اجرا کنید:

```bash
npm start
```

7. مرورگر را باز کنید و بروید به:

http://localhost:3000

## نکته امنیتی

کلید API را هرگز داخل فایل‌های داخل `public` قرار ندهید. این نمونه کلید را فقط روی سرور می‌خواند.

## مرحله بعد

برای استفاده واقعی توسط اعضای مجموعه، این پروژه باید روی یک سرور/هاست قرار بگیرد و بعد می‌توان برای آن دامنه اختصاصی، ورود کاربران، آرشیو اخبار و آپلود عکس اضافه کرد.
